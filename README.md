# TR Naja – Gestion de boutique

Logiciel de gestion en **un seul fichier** : `index.html`. Il marche hors ligne dans le navigateur.

- **Utiliser** : ouvrir `index.html`, ou le lien GitHub Pages (Settings → Pages → Source : *GitHub Actions*).
- **Partager entre appareils** : voir `pocketbase/README.md`.
- **Application Windows / Mac** : onglet *Actions* → *Build TR Naja EXE + DMG* → *Run workflow*, puis télécharger le résultat.

Attention : une page GitHub Pages est en https, donc elle ne peut parler qu'à un PocketBase en https.
